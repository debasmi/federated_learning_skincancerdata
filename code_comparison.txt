cnnfull(OLD CODE) vs cnn_epochopt(NEW CODE) - SIMPLE COMPARISON
=========================================

Old code = fixed 15 epochs, cosine learning-rate schedule
New code = early stopping (up to 60 epochs), plateau learning-rate schedule


1. How long it trains
   Old: Always exactly 15 rounds (epochs)
   New: Up to 60 rounds, but stops early if it stops getting better

2. Knowing when to stop
   Old: Never stops early, even if it is not improving
   New: Stops after 7 rounds in a row with no improvement (patience = 7)

3. Learning speed
   Old: Slows down a little every round, on a fixed plan
   New: Stays the same, then halves only when progress stalls

4. Wasted time
   Old: Can waste time on useless rounds
   New: Saves time by quitting when it is stuck

5. Risk of stopping too soon
   Old: None, because it always runs the full 15
   New: Small risk, since scores are noisy and more rounds might have
        found something better

6. Extra info reported
   Old: Accuracy, F1, AUC, time, model size
   New: Accuracy, F1, AUC, time, model size, which round was best, how many rounds ran,
        and the learning speed
